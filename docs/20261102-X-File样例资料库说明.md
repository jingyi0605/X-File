# X-File 样例资料库

这套样例使用独立的启动命令、文档库根目录、应用状态目录和 HTTP 状态文件，不会读取或覆盖默认的 `.x-file` 配置。

## 启动

在仓库根目录执行：

```bash
pnpm sample:start
```

启动命令会按需生成 `.x-file-sample`，然后启动独立的 Tauri desktop client。桌面窗口通过 native bridge 读取样例绑定、标签和运行时索引快照，不需要先启动默认 `.x-file` 配置。

- Tauri desktop client：独立启动
- Tauri 开发前端：`http://127.0.0.1:17340`
- 文档库：`.x-file-sample/library`
- 独立状态：`.x-file-sample/state`

退出桌面客户端或在启动终端按 `Ctrl+C`，脚本会结束 Tauri 开发进程和前端子进程。

如果只需要浏览器调试页面，可以使用：

```bash
pnpm sample:start:web
```

浏览器调试模式使用独立 HTTP 端口和 mirror 运行时配置；它不会替代 `pnpm sample:start` 的桌面客户端启动方式。

## 样例内容

默认生成 1200 份文档，平均分配到两个行业资料库：

- 软件开发：产品、架构、前端、后端、数据、质量、安全、交付和运维。
- 影视设计：剧本、分镜、美术、角色、摄影灯光、制片、剪辑、特效和交付。

文档覆盖 Markdown、纯文本、JSON、YAML、HTML、XML、CSS、SCSS、JavaScript、TypeScript、TSX、Python、SQL、CSV、Shell、RTF、日志、TOML、INI、SVG、Less、C、C++、Go、Rust 和 Java 等格式。

每份文档都包含：

- 不同的文件创建时间和修改时间；文件系统支持时会同步设置 macOS 创建时间，完整时间记录保存在样例清单中。
- 行业、阶段、专业视角、文件格式、生命周期状态和项目等手工标签。
- 对应的 `documentTags` 绑定，以及按资料库目录生成的 `folderTags` 绑定。
- 运行时索引快照和可供 X-File 列表、搜索、标签浏览使用的导出数据。

## 生成选项

只生成软件开发资料库：

```bash
pnpm sample:generate -- --industry software-development --count 1200 --reset
```

只生成影视设计资料库：

```bash
pnpm sample:generate -- --industry film-television-design --count 1200 --reset
```

`--count` 最小值为 1000。`--reset` 只作用于 `.x-file-sample` 或通过参数指定的样例目录；不传入时，已有样例会被保留并重新校验索引。

如果只需要生成文件和标签而暂时不生成运行时快照，可以使用：

```bash
pnpm sample:generate -- --skip-index
```

这种模式会留下完整文件、绑定配置和标签存储，之后重新执行不带 `--skip-index` 的命令即可补齐运行时快照。
