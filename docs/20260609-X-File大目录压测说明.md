# X-File 大目录压测说明

当前入口是 `scripts/benchmark-native-library.mjs`，直接调用 Rust 原生 CLI，不启动开发服务器，不使用 TypeScript 扫描器或 SQLite catalog。旧大目录脚本已删除。

## 准备

```bash
cargo build --manifest-path apps/desktop/src-tauri/Cargo.toml
pnpm --filter @x-file/shared build
pnpm --filter @x-file/indexer build
```

默认使用桌面端本地构建产物，也可以通过 `X_FILE_DESKTOP_CLI_PATH` 指定可执行文件。

## 执行

```bash
pnpm benchmark:index
pnpm benchmark:index -- --files 10000 --dirs 100
```

默认生成 1,000 个 Markdown 文件、50 个目录。资料库创建在系统临时目录，测试结束后自动删除；脚本不会写入现有资料库。

依次测量首次完整索引、无变化刷新、摘要词项未变化的单文件更新和摘要词项改变的单文件更新。文件生成和导出统计不计入 CLI 耗时。

## 输出

- `durationMs`：该轮原生 CLI 的实际耗时，包含进程启动。
- `rewrittenSnapshots`：本轮被替换的目录快照、活动文件快照和索引状态快照文件名；无变化刷新应为空。

- `scanned`、`indexed`、`unchanged`：源文件扫描、更新与复用数量。
- `rewrittenExports`：通过导出文件的 inode、修改时间和大小比对得到的实际新增或改写数量。
- `removedExports`：该轮删除的导出文件数量。

可增加 `--unchanged-runs 5` 重复测量无变化刷新。该脚本每轮启动独立 CLI，不复用桌面进程的内存缓存；桌面文件监听和空闲页面同步仍需启动桌面程序验证。

第一次单文件更新在现有内容末尾追加文本，摘要前缀保持不变，用于验证搜索桶复用；第二次替换文档内容，验证真实词项变化的更新成本。文件删除另由索引端到端测试覆盖。

调试构建的测量值仅用于当前机器的重复验证，不能作为正式发布包的性能承诺。
