# spec001.1-X-File 轻量 Office 预览

本 Spec 从移除 OnlyOffice 在线编辑器开始，逐步建设 X-File 的统一文件预览能力。Office 文件只读预览，编辑由桌面端调用系统默认应用打开原文件。

最新架构目标是建立可验证的格式能力清单、按文件家族组织的预览适配器，以及供主查看器、详情面板和独立窗口共用的 renderer 路由。参考 DSH 的交互能力和资源边界，不复制其整体布局或样式系统，也不把不同格式强行转换成同一种展示模型。

## 范围

- DOCX、XLSX、PPTX 提供应用内只读预览。
- 桌面端保留本地应用打开和文件管理器定位能力。
- 移除 OnlyOffice 设置、前端脚本、Native bridge、HTTP 回调和相关配置/API。
- 保留 Office 文件分类、索引摘要和文档库对外预览 DTO 的稳定性。
- PDF 使用连续页面、懒加载、缩放和页码定位。
- XLSX 保持只读工作表视图，支持工作表切换、单元格选区、复制和公式栏；不转 PDF。
- 明确区分可索引、可预览、可编辑能力，避免图标或索引支持被误认为有专用 renderer。
- 文本、Markdown、HTML、图片、PDF、Office、代码和不支持格式经统一适配器协议接入，并共享资源生命周期、加载/错误状态和桌面回退。
- Server 与 Rust 本地预览的格式分类通过共享契约或一致性测试防止漂移。
- 主查看器、详情预览和独立窗口复用相同的 renderer 分派与格式行为。

不迁移或清理现有用户目录中的旧 OnlyOffice 配置文件。
