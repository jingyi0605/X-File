# 外部 Agent 接入设置验收记录

日期：2026-10-26

状态：已完成本机桌面设置、CLI/MCP 鉴权与安装说明；完整前端测试的既有失败单独记录。

## 实现范围

- 设置的「集成服务」新增外部 Agent 卡片：默认关闭，配置密钥后才能启用。
- 支持自定义、生成、轮换、撤销密钥；撤销同时禁用。普通查询不返回明文，配置文件只存摘要；Unix 权限为 0600。
- CLI 调用与 MCP 启动通过 `X_FILE_AGENT_API_KEY` 校验；后续工具调用重新读配置，关闭和换钥使旧凭据失效。已经开始执行的操作不强制取消。
- MCP/CLI 示例采用实际程序和数据目录，默认只读，可切换为读写模板。示例使用密钥占位符，提供复制和错误提示。
- 展示 SKILL 导出、安装及验证步骤；Windows 命令明确设置 UTF-8 解码并写入无 BOM 的 UTF-8 文件。
- 镜像模式提示到资料库主机配置；浏览器和旧版本显示能力限制，不请求不存在的 HTTP 设置接口。
- 沿用 spec004，保留并行的任务中心和视觉改造；本轮改动未提交。
