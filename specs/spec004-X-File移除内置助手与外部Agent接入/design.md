# 设计文档 - 移除内置助手与外部 Agent 接入

状态：已完成（既有测试失败已在独立基线复现）

## 1. 目标与约束

覆盖需求 1、2、3。React 前端、Fastify 服务与 Tauri 桌面宿主只保留文档库及现有非助手集成。

用户已授权删除相关代码，并确认启动 spec004。实施前读取前端规范，保留工作区原有修改，不启动开发服务器。

## 2. 架构与数据所有权

### 2.1 当前关系

文档详情选择状态传入助手 hook，hook 调用 HTTP 助手接口；服务端通过插件清单加载会话同步运行时；桌面和 Node 同时维护供应商检测及插件注册表。仓库内两个集成插件均服务于内置助手，没有其他实际插件实现。

### 2.2 目标结构

文档详情只消费文档选择与预览状态。删除助手专用插件管理链路，ONLYOFFICE 独立保留。共享包仅导出文档库类型，服务端启动不再装配插件与助手。

未来的数据流为：外部 Agent → MCP / CLI → 文档库能力；SKILL 负责说明工具发现、参数、结果与错误处理。本轮仅记录方向，不新增未实现的接口承诺。

## 3. 组件和接口

### 3.1 前端

删除 `features/assistant`，文档详情移除助手分支、会话弹窗和上下文转换；设置移除助手插件卡片及请求。同步清理翻译、图标、助手专用 CSS 与测试桩，保留通用详情、模态框和预览样式。

### 3.2 后端与共享类型

删除助手目录、路由、专用插件模块和注册表，删除 `session-sync-core` 工作区包及服务端依赖。移除共享助手及插件类型导出和前端桥接。

原助手与专用插件 HTTP 地址返回正常的未注册路由响应；不提供兼容运行时。

### 3.3 桌面与打包

删除原生插件列表、开关、供应商命令与登录检测，以及仅为助手传递的插件目录环境变量。删除两个插件的源清单与打包副本。资源准备脚本仍负责清理旧 Node 资源，但不再部署插件；资源边界与验包检查同步更新。

## 4. 数据与兼容性

不更改文档库状态模型与用户文件。历史助手会话和插件注册表留在用户磁盘上，不再由软件加载。移除的助手及专用插件 API 属于本次明确要求的行为变化。

现有未提交修改涉及 README、文档页、翻译、原生索引和启动脚本；在当前内容上进行局部编辑，禁止覆盖。

## 5. 错误处理

移除的 API 沿用 Fastify 未注册路由处理。ONLYOFFICE、HTTP 服务状态与文档库沿用现有错误契约。

## 6. 正确性属性

1. 打开文档页或设置页不会触发助手、供应商、插件管理请求。
2. 启动服务无需会话同步包或助手清单。
3. 正式包资源不含内置 AI 插件，验包脚本不再要求这些资源。
4. 文档详情预览、ONLYOFFICE 和其他现有核心功能保持原有契约。

## 8. 风险

- 原生宿主内的命令检测或路径工具可能被非助手代码复用，删除前必须检查调用关系。
- CSS 混合规则可能同时服务预览，需要保留通用选择器。
- 完整安装包签名、跨平台发布和外部 Agent 工具实现不属于本轮验收。
