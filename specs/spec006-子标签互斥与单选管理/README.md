# Spec006：子标签互斥与单选管理

状态：完成

本 Spec 为现有树状标签管理增加父标签级的子标签选择模式。默认保持多选；开启单选后，同一父标签下的直接子标签在文件的有效标签中互斥，用户选择新标签时替换同组旧标签，自动来源冲突由统一解析器稳定裁决。

- `requirements.md`：业务需求、范围和可验证验收标准。
- `design.md`：配置模型、赋值及多来源冲突解析、兼容与测试策略。
- `tasks.md`：按依赖排序的实施任务及验收入口。
- `docs/`：实施期间的补充协议、验收记录或兼容说明。

实施前先复核当前主路径与现存工作区改动；默认不触碰本 Spec 以外的未提交文件。前端实现须遵循 `../../docs/20260609-前端开发规范.md`。
