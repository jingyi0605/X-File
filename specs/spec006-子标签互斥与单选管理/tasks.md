# 任务清单：子标签互斥与单选管理（人话版）

状态：Draft

## 这份文档是干什么的

按“先定清语义，再让数据模型、统一解析器和各入口采用同一规则，最后验证兼容性”的顺序实施子标签单选。实现期间逐项更新状态和真实验证结果。

## 状态说明

- `TODO`：还没开始
- `IN_PROGRESS`：正在做
- `BLOCKED`：被外部问题卡住
- `IN_REVIEW`：已经有结果，等复核
- `DONE`：已经完成，并且已经回写状态
- `CANCELLED`：取消，不做了，但要写原因

只有 `DONE` 的任务才能勾选 `[x]`。每项任务完成后立即写回本清单。
